# Durability-Prediction-of-GFRP-Bars-with-Interpretable-ML
We have uplaoded three excel files in this repo. 
The TabPFN_combined_pred_vs_true_data.xlsx contains the real output as well as predicrtions made by TabPFN for training as well as test set. 
The experimental_data_final.csv has the entire experimental data including training as well as test set. 
The xgb_test_predictions.xlsx has the test set (input as well as output) as well as predictions made by the XGBoost model.
